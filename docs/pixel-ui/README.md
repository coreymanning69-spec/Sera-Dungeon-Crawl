# Pixel UI Mockups

These files are generated pixel-style ASCII interface previews for the overlay system.

## Files

- `viewport.txt` — base combat viewport with BottomBar and no active overlay.
- `system_menu.txt` — blocking System Menu overlay (combat suspended).
- `status_screen.txt` — non-blocking status overlay.
- `loadout_screen.txt` — non-blocking loadout overlay.
- `log_screen.txt` — non-blocking log overlay.

## Regenerate

```bash
python scripts/export_ui_mockups.py
```
